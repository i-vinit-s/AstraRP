# AstraRP

AstraRP is a full-stack roleplay community platform built for FiveM roleplay communities. It includes Discord OAuth sign-in, whitelist/staff application flows, admin dashboard, and deployment-ready infra.

## Highlights
- Discord OAuth login + whitelist / staff applications
- Full-stack Next.js frontend with expressive UI (shadcn/ui + Tailwind)
- Express API for background tasks, user management, and integration with FiveM servers
- MongoDB for persistence, Redis for sessions and rate-limits
- Branded loader & polished UX (Framer Motion)

## Tech stack
- Frontend: Next.js (App Router), Tailwind CSS, shadcn/ui, Framer Motion
- Backend: Node.js + Express.js, Discord OAuth integration
- Database: MongoDB (Mongoose)
- Cache & sessions: Redis
- Real-time: Socket.IO
